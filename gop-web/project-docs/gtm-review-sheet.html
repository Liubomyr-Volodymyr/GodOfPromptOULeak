GTM Event Review

The dataLayer → GA4 contract for the clean gop-web build. Each row is one event the site pushes to window.dataLayer. Your job on the container side: confirm a trigger + a GA4 event tag exist for it, and that it lands in DebugView.

29events to wire
9key events
4server-side legs
3deferred
7GA4 auto — skip
How to review each row. Build one GTM trigger (Custom Event = <event name>) + one GA4 event tag that forwards the listed params. Register each param as a custom dimension. Tick the box once the trigger + tag exist and the event shows in GA4 DebugView. The event name and param names must match exactly — they map 1:1 to GA4.
